Execution summary

SatQuery AI — PS 26167

Interactive Vision-Language Assistant for Multimodal Remote Sensing Image Analysis through Text Queries — ISRO / Department of Space, Smart India Hackathon 2026.

  • Agentic orchestration — every query is validated, classified, routed to a registry of specialist tools (VQA · caption · grounding · change · optical-SAR fusion · numeric), executed with permitted parameters only, and merged into a combined answer.
  • Inputs — single optical/multispectral/SAR image · registered optical+SAR pair · bi-temporal pair. GeoTIFF/TIFF with georeference preserved in GeoJSON outputs.
  • RS adaptation — Qwen2.5-VL fine-tuned on BigEarthNet (LoRA, see scripts/train_lora.py), served locally through vLLM or via a cloud VLM for development.
  • Auditability — every response carries a validation report, execution trace (task, models, tools, parameters), confidence estimate, visual evidence and a downloadable HTML/JSON report.

All processing happens on the backend you are connected to — images are not stored beyond the in-memory query history.
